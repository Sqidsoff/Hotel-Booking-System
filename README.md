# HotelBook — standalone frontend

Це повністю standalone-версія шаблонів без Flask/Jinja2/Next.js.

## Запуск

Можна просто відкрити `index.html` у браузері.

Для зручності також можна запустити локальний static server, наприклад:
- VS Code Live Server
- `python -m http.server`

## Демо

Адміністратор:
- Email: `admin@hotel.local`
- Пароль: `admin123`

Новий гість реєструється через `register.html`.

## Що працює

- адаптивна навігація;
- пошук номерів за типом/номером, датами та кількістю гостей;
- перевірка перетину бронювань;
- реєстрація та вхід;
- створення бронювання;
- сторінка "Мої бронювання";
- адмін-панель;
- зміна статусів бронювань;
- зміна статусів номерів;
- додавання платежів;
- підрахунок оплаченої суми;
- збереження даних у `localStorage`.

## Важливо

Це frontend-only demo. Паролі та дані зберігаються у браузері через `localStorage`, тому це НЕ є реальною системою авторизації.

Коли backend/API буде готовий, функції роботи з `localStorage` можна замінити на `fetch()` до API.
